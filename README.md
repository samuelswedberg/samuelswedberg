## Featured Project: Sim Racing Wheel System

Year-long senior capstone at NDSU: a full sim racing force feedback system (wheelbase, steering wheel, and pedals) built from scratch. It earned top faculty and industry feedback at the NDSU Senior Design Expo.

- **Firmware:** STM32 with FreeRTOS for real-time motor control, a USB OTG HID device driver, and peripheral management
- **Communication:** Multi-device CAN bus network across 3 custom two-layer PCBs
- **Software:** Python PC app for user settings and game telemetry over serial
- **Hardware:** Mechanical parts modeled in Fusion 360, 3D-printed enclosures and structural parts (PA6-CF and ABS), full PCB design and system integration
- **Validation:** Oscilloscope, logic analyzer, and multimeter for hardware debugging and signal verification
